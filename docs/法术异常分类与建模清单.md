# 法术异常分类与建模清单

## 范围与统计口径

本文整理 TRPG Helper 的 2024 规则法术可能给战斗建模带来的特殊机制。“异常”是本项目为设计方便使用的术语，**不是官方规则术语**，也不表示这些效果违反规则。当前方案将机制分成 **16 个大类、64 个子类**；这是设计分类的数量，不是法术数量，也不是对所有可能规则例外已经穷尽的证明。

同一法术可以同时属于多个大类或子类；子类之间也可以交叉。基本规则和某个法术的特殊规则应分开记录：每一项最终仍须核对具体规则来源、版本和原文，而不是根据本文的类别自动推断。

以本机已导入的 339 条 SRD 法术描述为基数，本地未提交原型中有 6 个法术的部分异常规则注解，**339 条的战斗自动结算状态仍为人工裁定**。这些原型及其关键词审计工具不包含在本文档提交中。没有对 339 条进行逐条人工分类，因此本文不提供各类覆盖的法术数量，也不声称六个法术的全部规则已建模；关键词审计只用于提示，不能当作分类结果。

分类依据包括 [2024 施法规则](https://www.dndbeyond.com/sources/dnd/br-2024/spells)、[2024 规则术语表](https://www.dndbeyond.com/sources/dnd/br-2024/rules-glossary)、[2024 法术描述](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions)和 [SRD 5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf)。若版本或官方勘误不同，应按所选规则版本重新核对。

## 01 目标资格与选择

**模型数据**：目标种类、数量、距离与视线要求、资格谓词、是否允许重复选择、选择时点。

1. **生物类型与对象种类**：生物、类人生物、物体或魔法效应等，按法术限制选择。
2. **自愿与状态资格**：自愿或不自愿、存活或死亡、是否具有特定状态。
3. **感知与可达性**：要求可见、接触、可见空位或其他特定条件；与范围遮蔽分开判断。
4. **数量与目标关系**：单目标、多目标、同一对象能否被重复选择，以及目标间距离等附加要求。

例：*Hold Person* 要求选择看得见的类人生物；*Misty Step* 的目的地要求可见且未被占据。当前有部分注解，尚无自动目标合法性检查。

## 02 作用范围与空间几何

**模型数据**：起点、形状、尺寸、朝向、空间维度、遮蔽规则、单位覆盖计算方式。

1. **基本几何形状**：球、锥、立方、圆柱、线、散发等，不将射程与区域尺寸混为一谈。
2. **区域原点与朝向**：以施法者、指定点、目标或物体为起点；指定方向和放置位置。
3. **复杂形状与边界**：墙体、环形、可变尺寸、环绕角落等具体描述。
4. **覆盖与阻挡**：判定受影响对象、边界接触、完全遮蔽和其他针对区域的限制。

例：*Fireball* 以指定点为中心形成球形区域；*Wall of Fire* 允许不同墙体形状。几何行为尚无自动实现。

## 03 攻击、豁免与结果分支

**模型数据**：投掷者、检定类型、使用的能力、DC 或攻击加值、结果分支与独立性。

1. **攻击命中与未命中**：近战／远程法术攻击；命中、失手及临界命中如何处理。
2. **豁免成功与失败**：每个目标独立进行豁免，分别产生无效、半伤或其他效果。
3. **重复检定与终止**：效果期间何时重复豁免、成功后对谁生效、是否有次数或免疫限制。
4. **特殊替代与自动结果**：自动命中、无须投掷、触发条件下替换投掷或特殊检定。

例：*Hold Person* 的重复豁免成功仅结束该目标身上的效果。当前有部分注解，尚无投掷执行器。

## 04 伤害、治疗与生命状态

**模型数据**：数值表达式、类型、目标、时间、成功／失败分支，以及伤害来源。

1. **即时和分段伤害**：一次、多段、延迟触发或不同伤害类型；各段的触发条件分开记录。
2. **减半与防护交互**：半伤、抗性、免疫、易伤等应按规则明确顺序和作用范围。
3. **治疗与临时生命值**：恢复量、上限、不能叠加或替换的规则、来源和结束时清理。
4. **生命上限与特殊变化**：生命上限增减、当前生命同步变化、效果结束后的恢复方式。

例：*Shield* 对魔法飞弹伤害有特殊防护；*Polymorph* 与临时生命值及其清理有关。当前只有部分注解。

## 05 状态、属性与能力修改

**模型数据**：状态或属性键、修改方式、来源、适用条件、优先级、结束条件。

1. **标准状态**：例如麻痹、失明、恐慌，记录施加、免疫和移除条件。
2. **数值修正**：AC、速度、攻击、检定、豁免等增减或替换，以及适用范围。
3. **优势、劣势与行动限制**：限定使用时机、允许的行动及附加能力。
4. **效果叠加与冲突**：同名效果、不同来源和不同计算方式如何选择或覆盖，须按具体规则确定。

例：*Haste* 同时修改速度、AC、豁免和额外行动；不能只用一个“增益”标签表达。

## 06 持续、专注与生命周期

**模型数据**：持续类型、开始时点、最大持续时间、结束事件、关联实体和清理动作。

1. **瞬时与固定时长**：瞬时、回合、分钟、小时或其他时段，并记录从何时开始计时。
2. **专注维护**：新的专注效果、受伤豁免等导致的中断与结束。
3. **提前终止**：施法者结束、目标满足条件、被解除、资源耗尽或死亡等。
4. **结束后果和清理**：移除区域、状态、召唤物或临时生命，以及结束时产生的额外效果。

例：*Polymorph* 的临时生命值在法术结束时的处理需使用对应规则版本；SRD 5.2.1 的勘误不能被旧导入文本覆盖。

## 07 事件触发与时序

**模型数据**：监听事件、作用主体、触发时点、执行频率、有效期限及事件链。

1. **回合起止触发**：施法者、目标或其他生物的回合开始／结束时分别处理。
2. **进入、离开与停留**：创建区域时、进入区域时或在区域中开始／结束回合时的不同效果。
3. **攻击、受伤与行动触发**：命中、受到伤害、施法或特定行动前后触发的效果。
4. **延迟与预设条件**：提前设置触发事件，可能跨战斗或在脱离当前回合后触发。

例：*Glyph of Warding* 和 *Contingency* 涉及预设条件，不宜简化为立即生效的动作。

## 08 反应、打断与窗口

**模型数据**：触发事件、响应资格、反应资源、执行窗口、被中断事件的恢复或取消方式。

1. **反应资格**：可见性、距离、反应是否可用，以及法术自身指定的触发条件。
2. **命中前后窗口**：在命中已确定后响应时，是否改变本次攻击结果需按法术处理。
3. **施法中断**：成功或失败的分支，以及原施法的动作、法术位和其他资源各自如何处理。
4. **嵌套响应与冲突**：多个角色响应同一事件时的顺序、窗口关闭和不可用响应。

例：2024 版 *Counterspell* 的体质豁免及原施法资源处理，与 2014 版不应混用；*Shield* 可能影响触发它的攻击。

## 09 法术之间的交互

**模型数据**：目标效果实例、规则版本、环阶、来源、可被影响的范围和解除结果。

1. **法术反制**：针对正在施放的法术，区分触发者、响应者和被影响施法。
2. **解除持续效果**：针对生物、物体或魔法效应；逐个确定自动解除或需要检定。
3. **重复施放与并存**：同名效果来自不同施法者或不同时间时，按适用规则判断。
4. **特定法术免疫或限制**：某效果只防止、修改或限制特定法术或特定类型的效果。

例：*Dispel Magic* 对目标上的每个更高环阶持续法术分别检定；*Shield* 专门防止魔法飞弹伤害。

## 10 施法资源、成分与升阶

**模型数据**：资源来源与数量、消耗时点、材料及价值要求、环阶或角色等级参数。

1. **动作经济与法术位**：动作、附赠动作、反应、法术位或其他特性资源的使用。
2. **材料、价值与消耗**：材料是否必须持有、最低价值、是否消耗及替代方式。
3. **升环变化**：每高一环增加伤害、目标、范围、时长或其他数值，具体按法术记录。
4. **戏法成长与免费施法**：按角色等级成长，或通过特性施法时不同的消耗和限制。

例：*Hold Person* 升环增加目标；*Counterspell* 失败的被反制施法有特定法术位处理。材料与免费施法仍需单独建模。

## 11 移动、传送与空间占用

**模型数据**：移动主体、距离、方向、目标位置、可见性、占位及途中规则。

1. **自愿或强制移动**：推、拉、直线移动，是否需要路径以及被阻挡时的处理。
2. **短距传送**：目的地可见、未占据、地形与空间限制。
3. **跨区域或跨位面移动**：目的地选择、携带对象、返回路径和失败后果。
4. **移动触发交互**：移动与区域、地形、其他效果或攻击机会的关系，以具体规则为准。

例：*Misty Step* 的部分目的地约束已录入，地图和位移规则尚未实现。

## 12 持续区域与场景对象

**模型数据**：区域／对象 ID、位置、大小、可否移动、视觉和环境属性、生命周期。

1. **区域生成与维持**：墙、场、屏障或区域随施法者／对象移动，或固定在某处。
2. **区域内的持续属性**：光照、声音、可见性、地形、伤害类型免疫或其他局部效果。
3. **可交互与可破坏对象**：被攻击、移动、穿越或解除时的条件及后果。
4. **区域终止与清理**：持续时间、专注、施法者或场景对象状态变化导致的消失。

例：*Silence* 会影响区域内声音和言语成分；这些条件不等于对区域内所有施法一律禁止。

## 13 召唤、创建与复制实体

**模型数据**：实体模板或来源、数量、创建位置、控制者、行动权、持续和清理。

1. **创建生物**：可选模板、挑战等级或其他限定，是否有独立属性和回合。
2. **创建物体或魔法实体**：效果可能表现为物体或区域，并不一定是可独立行动的生物。
3. **控制与行动权限**：友敌关系、指挥方式、执行时机和无指令时的行为。
4. **复制与结束处理**：复制时保存哪些数值、资源是否共享、结束或死亡后怎样清理。

例：2024 版 *Conjure Animals* 的效果应按具体描述建模，不能仅凭名称假定一定创建独立怪物；*Simulacrum* 则涉及复制。

## 14 变形、形态与装备

**模型数据**：新形态来源、可选范围、替换与保留字段、行动限制、装备和还原规则。

1. **形态资格**：生物种类、挑战等级、目标等级、已见过与否等限制。
2. **数值替换与保留**：区分生物类型、生命值、生命骰、属性、人格等，依具体法术决定。
3. **临时生命与提前结束**：临时生命值的来源、耗尽与法术结束时的清理。
4. **装备及动作能力**：装备融入、落地或适配；形态是否允许讲话、施法与其他行动。

例：*Polymorph* 的部分异常已记录；其他变形法术不能直接套用相同保留字段。

## 15 死亡、复活与长期后果

**模型数据**：目标生命状态、死亡时间、身体条件、资源代价、恢复结果及长期影响。

1. **濒死与死亡状态**：作用于 0 生命、稳定或已死亡目标时，分别判断适用条件。
2. **复活资格与时限**：死亡多久、死因及其他法术所要求的条件。
3. **身体与恢复限制**：是否恢复缺失身体部位，复活后生命值及持续影响。
4. **跨战斗后果**：永久效果、长期减益和需休息／特定事件结束的结果，不随战斗结束自动消失。

例：*Revivify* 对死亡时间和死因有明确限制；不能把所有复活法术做成“生命值加一”。

## 16 元规则、嵌套法术与人工裁定

**模型数据**：被选择的法术、来源与等级、替代条件、触发条件、明确未支持的部分。

1. **复制或替代法术**：记录被复制法术及其参数，区分正常施法与直接产生效果。
2. **嵌套或储存法术**：一个法术携带另一个法术及其施法者、目标、触发条件和资源代价。
3. **规则豁免与特定例外**：某次施法豁免材料、距离或其他一般要求时，只在规则允许的范围内生效。
4. **自由描述与主持人裁定**：开放式效果、条件不完整或无法机器判定的情况保留原文和人工决议。

例：*Wish* 可有多种选择；复制法术和自由效果必须区分，不能假定所有用途都有同一自动结算结果。

## 实施顺序与验收

| 阶段 | 重点 | 验收条件 |
| --- | --- | --- |
| P0：共同基础 | 目标、范围、检定、基础伤害、状态、时序、资源和手动裁定 | 能表示未识别内容；多目标逐个结算；测试命中、成功／失败与资源不变量 |
| P1：持续与响应 | 专注、重复触发、反应、解除、持续区域、传送 | 每个效果有来源和终止条件；中断不产生部分错误提交；可测试时间线和清理 |
| P2：复杂实体与特殊法术 | 召唤、形态替换、复活、嵌套法术和开放规则 | 测试创建、控制、还原和跨战斗边界；无法覆盖的分支明确交给主持人 |

阶段顺序是项目建议，不表示某阶段已经完成。具体法术标记为可自动结算之前，至少需要：锁定规则来源与版本；录入全部目标、触发、选择和结果；覆盖成功、失败、边界与清理的测试；明确未支持分支；通过规则核对。规则数据、一次施法请求和战斗运行时状态必须分离，不能将战斗中的法术位或专注状态写回已发布角色。
