# 人物与怪物模板 v1

本目录提供 JSON Schema 2020-12 数据契约和虚构示例；它们是数据结构，不是图鉴、车卡、规则引擎或战斗系统的实现。

- `schemas/character-draft.schema.json`：可以不完整的车卡草稿，不可作为发布快照或战斗单位使用。
- `schemas/character-snapshot.schema.json`：对应现有《车卡导入战斗_数据契约_v1.0.md》的发布快照结构，保留构筑、规则来源和静态数值，不包含当前 HP 等战斗状态。
- `schemas/monster-entry.schema.json`：怪物资料包含一张或多张独立数据卡；动作保留描述与自动化状态。不同版本数据卡应有独立 ID 和规则绑定。
- `schemas/common.schema.json`：共享六维、规则绑定和能力字段。
- `examples/`：结构演示，规则包、哈希及数据均为虚构占位值，不可用于真实规则结算。

在仓库根目录运行 `pnpm install --frozen-lockfile`，再运行 `pnpm test`。导入时应注册共享 schema，再验证对应版本；未知字段会被拒绝，调用方不得静默丢弃。

结构校验不等于规则合法：等级总和、选择条件、真实规则包及哈希、重复数据卡 ID、能力引用、版本兼容性和发布内容摘要都需要后续领域层校验。`effectRef` 仅是待解析的引用，不代表已有可执行能力。当前没有发布流程、哈希生成、自动结算、战斗导入、持久化或用户界面。数据卡中的复杂条件暂用说明文本保留；战斗引擎不得将文本当作已实现的效果。

后续修改 schema 应增加版本和迁移器，不得直接改变已发布文档的含义。公开内容须分别确认数据、翻译和图片的使用许可。
